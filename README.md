# 🎓 Student Performance Prediction

## 📌 Project Overview

This project uses Machine Learning to predict student math scores based on various factors such as reading score, writing score, gender, parental education, lunch type, and test preparation course.

The project demonstrates:
- Data preprocessing
- Exploratory Data Analysis
- Feature encoding
- Model training
- Prediction and evaluation

---

# 🎯 Objective

✔ Build a Machine Learning prediction model  
✔ Analyze student performance data  
✔ Train and evaluate Linear Regression model  
✔ Generate predictions using real-world data
